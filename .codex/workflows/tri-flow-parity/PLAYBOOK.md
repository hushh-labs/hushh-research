# Tri-Flow Parity

Use this workflow when a change must declare or audit Web, iOS, and Android parity.

1. Start with `mobile-native`, then use the `tri-flow-parity` spoke.
2. Read the route inventory and excluded-route reason contract before changing a declaration.
3. Run the static parity and surface-map checks.
4. Record every platform impact or an explicit reason it is not applicable.

# Provider readiness diagnostics

Automatic pre-merge AI review is retired. The Readiness Exam workflow is removed;
it must not be requested by preflight, merge admission or deployment. Historical
receipts remain evidence of their original runs, never current release authority.

Provider qualification belongs to an explicitly selected release operation using
the existing [managed-provider procedure](managed-provider-readiness.md). Offline
grader and manifest tests remain available for changes to those contracts.

Keep the historical probe environment restricted to Main while any Entra trust
still names it. Removing the workflow is not revocation of its cloud identity.
Do not recreate a live AI-review workflow or broaden that environment.

# One Location place ratings.
#
# The first durable link between a person and a venue this product has ever
# kept, so the guards below hold the properties that cannot be fixed after
# launch: a rating is writable only by someone the server recorded at the
# place; the visit ledger holds the venue only as ciphertext; a rating row
# carries no author display identity for a future read path to leak; one
# person gets one vote per place; and no average is published until enough
# people have rated that the average is not a re-identification of one of them.
#
# This manifest is the only pytest invocation in any lane, including the merge
# queue, so a test absent from it is decoration.

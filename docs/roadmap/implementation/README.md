## Design material

[Plans](plans/README.md) and [design proposals](specs/README.md) retain requirements
whose completion needs reconciliation with their workstream owner. Read current
module contracts first. Do not follow an old implementation checklist as a release
procedure or infer availability from a proposal.

When work finishes, reconcile unique durable facts into the owning Architecture,
Development or Operations page and retire the completed plan. Preserve required
provenance outside narrative copies. See [documentation maintenance](../../development/documentation.md).

\# Semantic HTML Guide



\## Purpose



Semantic HTML improves:

\- accessibility

\- maintainability

\- readability



\## Recommended Elements



| Purpose | Recommended Tag |

|---|---|

| Navigation | `nav` |

| Main content | `main` |

| Articles | `article` |

| Sections | `section` |

| Buttons | `button` |



\## Accessibility Benefits



Semantic HTML improves:

\- screen reader support

\- keyboard navigation

\- content structure understanding

\# Semantic HTML Guide



\## Purpose



Semantic HTML improves:

\- accessibility

\- maintainability

\- SEO

\- readability



---



\## Recommended Elements



| Purpose | Recommended Tag |

|---|---|

| Navigation | `nav` |

| Main content | `main` |

| Articles | `article` |

| Sections | `section` |

| Buttons | `button` |

| Forms | `form` |



---



\## Avoid



\- Excessive nested `div` elements

\- Clickable non-semantic elements

\- Missing heading hierarchy



---



\## Accessibility Benefits



Semantic HTML improves:

\- screen reader support

\- keyboard navigation

\- content structure understanding

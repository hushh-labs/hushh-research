\# Accessibility Checklist



\## Semantic HTML



\- Use semantic tags like `header`, `main`, `section`, and `button`

\- Avoid excessive `div` usage

\- Ensure proper heading hierarchy



---



\## Keyboard Navigation



\- All interactive elements must be keyboard accessible

\- Ensure visible focus states

\- Avoid keyboard traps



---



\## Forms



\- Every input must have a label

\- Use descriptive placeholder text

\- Provide validation feedback clearly



---



\## Images



\- Use descriptive `alt` text

\- Avoid decorative images without purpose



---



\## ARIA Usage



\- Use ARIA only when semantic HTML is insufficient

\- Avoid unnecessary ARIA roles



---



\## Color Contrast



\- Ensure readable text contrast

\- Avoid relying only on color for meaning



---



\## Testing



\- Test keyboard navigation manually

\- Validate semantic structure

\- Verify screen reader compatibility where applicable

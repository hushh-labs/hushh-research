# DM Sans web fonts

These self-hosted variable WOFF2 files are the Latin and Latin Extended normal
and italic subsets served by Google Fonts (DM Sans v17). DM Sans is distributed
under the SIL Open Font License 1.1; see `OFL.txt` in this directory.

Source: https://fonts.google.com/specimen/DM+Sans and
https://github.com/google/fonts/tree/main/ofl/dmsans

The product uses this licensed geometric typeface as a visual analogue to the
`optimisticAI` stack observed on Muse's public site. It does not embed Meta's
font files.

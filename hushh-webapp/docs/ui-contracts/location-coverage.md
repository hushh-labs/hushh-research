## Historical evidence

The 22–24 October 2026 coverage inventory is preserved in
[its immutable Git revision](https://github.com/hushh-labs/hushh-research/blob/6b6299ecb45f44f292e489e1167e75212c921718/hushh-webapp/docs/ui-contracts/location-coverage.md).
It records 1,144 text/accessibility sites, 163 action records (162 concrete
contracts and one unbound `local.default` fallback), and 104 exclusions.
Its JSON includes source templates, branch bindings, screenshot hashes and
explicit gaps. Preserve that revision for reproduction; do not copy its embedded
source snapshots back into maintained documentation.

Those counts describe the recorded source inventory. They do not prove every
conditional state rendered, every current action succeeded, or an old screenshot
matches the current application. The 24 October source-presence reconciliation
and CTA supplement are historical evidence with their original revision and
verification limits. Current native, permission, provider, account and delivery
claims require the owning acceptance record and actual runtime evidence.

This maintained page replaces the 6.6 MB embedded inventory with its provenance
and current owners. Git history retains the complete unique evidence.

## Authority and entry

`/one/consent` is the only Consent workspace. `app/one/consent/page.tsx` mounts `ConsentCenterPage` behind the signed-in guard and shows “Loading access manager…” while its Suspense branch loads. `/consents` shows “Opening access manager…” while preserving supported query parameters and replacing the route. `consent-sheet-controller.tsx` translates retained legacy sheet and Profile entry parameters into this route. No Shield inbox or separate modal workspace is mounted in `top-app-bar.tsx`.

The route uses the shared Back, Profile and navigation owners. The active actor is One for missing `actor`, `actor=one` and legacy investor input. Only exact `actor=ria&view=outgoing` admits the supported advisor context. The selected tab is `requests`, `active`, `history` or `connections`; `pending`, `previous` and `relationships` are compatibility aliases. `requestView=sent` selects Sent documents outside the RIA compatibility route. `requestId` or `selected`, with `bundleId` fallback, selects the detail. `page`, deferred `q`, `notificationAction`, `commerceRequestId` and validated internal `from` have their existing owners. Tab switches clear list/search/detail state while retaining the supported RIA and `from` context; detail close removes its own selection parameters and preserves tab/page/search. See `lib/navigation/top-shell-tabs.ts`, `lib/consent/consent-sheet-route.ts` and `components/consent/consent-center-page.tsx`.
